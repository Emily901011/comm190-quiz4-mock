Formula sheet

  • P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
  • Independent: P(A ∩ B) = P(A)P(B), and P(A | B) = P(A)
  • Dependent: P(A ∩ B) ≠ P(A)P(B), and P(A | B) ≠ P(A)
  • Mutually exclusive: P(A ∩ B) = 0, and P(A | B) = 0
  • P(A | B) = P(A ∩ B) / P(B)
  • P(not A ∩ not B) = 1 − P(A ∪ B)
  • Bayes: P(A | B) = P(B | A)P(A) / [P(B | A)P(A) + P(B | not A)P(not A)]
  • RAND()*k is uniform on 0 to k, so P(interval) = interval length / k
