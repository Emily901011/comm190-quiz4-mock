Formula sheet

  • P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
  • Independent: P(A ∩ B) = P(A)P(B), and P(A | B) = P(A)
  • Dependent: P(A ∩ B) ≠ P(A)P(B), and P(A | B) ≠ P(A)
  • Mutually exclusive: P(A ∩ B) = 0, and P(A | B) = 0
  • P(A | B) = P(A ∩ B) / P(B)
  • P(not A ∩ not B) = 1 − P(A ∪ B)
  • Bayes: P(A | B) = P(B | A)P(A) / [P(B | A)P(A) + P(B | not A)P(not A)]
  • RAND()*k is uniform on 0 to k, so P(interval) = interval length / k

IF formula, one RAND() cellWrite the interval that reaches the output. Probability = interval length / width of the range. a + RAND()*k runs from a to a + k.Multiplying the two tests. They read the same cell, so subtract.
IF formula, two RAND() cellsTrace each path to the output. Multiply along a path, then add the paths.Forgetting the output can also appear on the outer false branch.
“Are they independent?”Find P(A ∩ B), using P(A) + P(B) − P(A ∪ B) if needed. Compare it with P(A)P(B). Equal means independent.Thinking that events which can happen together must be dependent.
Mutually exclusiveP(A ∩ B) = 0, so P(A ∪ B) is the plain sum and P(A | B) = 0. With positive probabilities, these events are always dependent.Reversing it. Dependent events are not always mutually exclusive.
“At least one” or “neither”Use the complement: 1 − P(none). Neither = 1 − P(A ∪ B). Only if independent, neither = (1 − P(A))(1 − P(B)).Adding probabilities and counting the overlap twice.
Draws without replacementDraw the tree. The second branch uses one fewer ball. Multiply along paths and add the paths you need.Keeping the same denominator on the second draw.
“If” or “given”The condition is the denominator. Keep only the paths or table cells that satisfy it, then compute the part you want / all that remain.Stopping at the joint probability, or dividing by the wrong event.
Counts of people or itemsBuild a 2 × 2 table. Total − neither = union, and P(A) + P(B) − union = both.Taking the numerator from the wrong row of the table.
Bayes: reversed questionDraw the tree from the given rates. Answer = the one path you want / every path with the observed result.Giving the rate in the question, such as P(flag | fraud), when it asks for P(fraud | flag).
999 or not?Enter 999 only if nothing fixes P(A ∩ B). A union or a conditional would give it, so check for those first.Assuming independence just to get a number. “Dependent” alone gives no value.
